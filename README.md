# Object-detection-on-HERIDAL-YOLO-
##
Датасет HERIDAL содержит снимки, сделанные с дронов в рамках задач поисково-спасательных операций . Основная сложность задачи — люди на кадрах занимают очень малую площадь , часто частично скрыты растительностью или находятся в больших скоплениях, что делает детекцию нетривиальной.
В работе не реализуется детектор с нуля — задача заключалась в том, чтобы корректно подготовить и проверить датасет, а также запустить end-to-end обучение YOLO в реализации библиотеки Ultralytics.
##
- **Подготовка датасета**: распаковка и проверка структуры (train/valid/test, images/labels, data.yaml)
- **Разметка YOLO**: разбор формата class_id x_center y_center width height, реализация перевода нормализованных координат в пиксели
- **Проверка качества данных**: сравнение количества images и labels по каждому split, поиск пустых label-файлов, анализ распределения числа объектов на кадр
- **Визуализация**: случайные примеры из train/valid/test с корректно нанесёнными bounding box
- **Обучение**: YOLOv8n, 30 эпох, imgsz=640, batch=16
- **Оценка качества на валидации**: mAP50 = 0.735, mAP50-95 = 0.319, Precision = 0.71, Recall = 0.68
